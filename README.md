# Dispatch — русская озвучка

[Скачать патчер](https://github.com/lacost2001/Dispatch-RU-Dub/releases/latest)

Версия **0.2-preview** для Steam-сборки **24008174** на Windows 10/11.

Включено **6720 реплик с подтверждёнными звуковыми привязками**, 6464 звуковых записей, 29 банков. Первая версия включала 4137 реплик. Подобраны отдельные голоса персонажей; сохранены согласованные эффекты Голема, Сонара, Призмы и Полога.

Учитываются части фраз, начало воспроизведения с середины файла, продолжения через смену сцен и одновременные голоса. Короткие русские формулировки адаптированы по оригинальной речи, где это необходимо для длительности.

Из 7283 ранее созданных текстов для **563** активная запись в текущей игре не подтверждена. В этот список входят старые идентификаторы, текстовые узлы без подходящей записи и отсутствующие в текущих данных строки. Это отдельная категория, а не автоматически 563 пропущенных звучащих реплик. Подробности находятся в `Покрытие.csv` внутри архива.

## Установка

1. Скачайте и полностью распакуйте `Dispatch-RU-Patcher-v0.2.zip` из Releases.
2. Закройте игру и запустите `Dispatch-RU-Patcher.exe`.
3. Выберите папку Dispatch и нажмите **Установить**.
4. Дождитесь завершения, затем запускайте игру обычным способом.

`Dispatch-RU.data` должен лежать рядом с программой. При отсутствии прав на папку Steam запустите патчер от имени администратора. Python, аккаунт ElevenLabs и API-ключ для установки не нужны.

## Автообновление

При запуске патчер проверяет этот репозиторий и скачивает новую программу вместе с пакетом голосов. Архив и оба основных файла проверяются по SHA-256. Версии хранятся отдельно в `%LOCALAPPDATA%/DispatchRU/versions`.

Уже установленная озвучка обновляется автоматически, если игра закрыта. Во время игры замена запрещена. Без сети можно использовать ранее скачанный пакет. Версия 0.1 обновляется напрямую.

## Восстановление

Кнопка **Восстановить** возвращает исходные звуки. Оригиналы сохраняются в `Dispatch/Content/FMOD/Desktop/.dispatch-ru-backup-v01`. Не удаляйте резервные копии до восстановления.

Патчер проверяет точное содержимое банков и останавливается при неизвестной версии игры или сторонних изменениях. При прерванной установке сначала выполните восстановление.

## Проверки и ограничения

Банки проверяются через FMOD из установленной игры: декодирование, количество событий, число звуковых кадров, каналы и частоты. Нетронутые сжатые записи сохраняются побайтно. Есть проверки чистой установки, обновления, повреждённых пакетов, чужих изменений и восстановления после сбоя.

Полное прохождение всех веток и прослушивание каждой реплики человеком не выполнялись. Фоновая речь без субтитров может оставаться английской. Отчёты `Привязки.csv` и `Проверки.json` включены в архив.

## Исходный код

Программа использует .NET Framework и стандартные библиотеки Windows. Сборка: `powershell -ExecutionPolicy Bypass -File .\Build.ps1`. Проверки установщика на искусственных файлах: `python .\Test-Patcher.py` после сборки.

В Git хранятся исходники программы. Голосовой пакет публикуется в Releases; исходные игровые DLL и полная копия игры не распространяются. Лицензия MIT относится только к коду патчера.
